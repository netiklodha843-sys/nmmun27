# NMMUN '27 — Landing Page

Single-page website for Narsee Monjee Model United Nations (18th Edition), NMIMS Shirpur.

## Features
Animated globe hero, sticky nav with mobile menu, scroll progress, "Choose Your Chamber" committee accordion, delegate journey, schedule with line reveal, animated accessible FAQ, responsive and reduced-motion friendly.

## Tech
HTML5, CSS3, vanilla JavaScript. Fonts: Cormorant Garamond and DM Sans (Google Fonts).

## Run locally
Open `index.html` in a browser, or use the VS Code "Live Server" extension.

## Customise
Edit the `CONFIG`, `COMMITTEES` and `FAQS` objects at the top of `script.js`. Set `REGISTRATION_URL` to your form link. Colours and fonts are CSS variables at the top of `style.css`.

## Deploy
Push to GitHub, then Settings → Pages → Deploy from branch `main` / root.
